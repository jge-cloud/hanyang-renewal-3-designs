후보별 변경

후보 1
블루 콘트라스트		파랑 면 + 큰 자동차 실내 사진의 좌우 첫 화면. 수치 패널을 사진 아래 한 줄(설립·사업·위치)로 축소. 사업 2개 카드를 소재(단면도)·부품(실제 부품 3종) 교차 행으로 재구성. 대표 제품(TRUNK LID) + 나머지 6종 위계. 배합 막대 삭제 → 5종 칩만 남기고 상세 링크.사진이 파랑 면에서 열리며 안착, 네이비·파랑 면이 다가오며 전폭으로 펼쳐짐단독
후보 2
와이드 시네마		첫 장면 크롭을 바꿔 제목은 위쪽 바위 영역, 자동차는 오른쪽 아래로 분리. 흰 사각형 로고 → 원본 GIF에서 배경을 분리한 투명 흰 글자 로고. 도입 문단을 한 문장으로 축소. 생산시설은 실제 사진 2장을 한 줄로 묶은 어두운 띠. 제품은 같은 흰 칸·같은 높이, 원본 1.5배 이하. 수치 영역을 ‘걸어온 길’(연도·출처 표기)로 변경.첫 장면 확대→안착과 제목 줄 올림, 교차 이미지가 가장자리에서 열림단독
후보 3
파트 앤 매터리얼		부품 선택 레일 재설계: 데스크톱 5개·모바일 2개 노출, 이전/다음 버튼, 방향키, 선택 상태 밑줄, 위치 표시. 선택하면 사진·이름·조성 설명·제품구조·종류별 미니 단면이 함께 바뀜. 구조 탭은 종류별 실제 층 구성(TLS 3층 등)으로 다시 그림, BS-NS는 자료 없음 표기. 회사 영역은 사업장 + 2015 브로슈어 실사 3장.선택 → 사진·설명·구조 연결 전환, 탭단독
후보 4
웜 레이어		원료(목재 원료 사진)→소재(NPS 시트)→부품(실제 DOOR PANEL)을 크기가 줄어드는 세 장면으로 연결. 공정 4단계를 도형 + 한 줄 설명으로. 특징 카드 3개 → 큰 문장 하나. 부품은 큰 띠 위 4종. 가로 연혁 삭제 → 4줄 요약 + 전체 연혁 링크. 적갈색은 화살표·진행선·산업용 구분선에만.원료→소재→부품 순차 연결, 공정 진행선단독
후보 5
테크니컬 인덱스		NPS 문자 아래 기술 도해(코어 표면 확대 + 단면, 두께 범위) + 실제 시트·원료 사진. 사업 설명은 항상 펼쳐진 상태, ‘세부’에서 근거·링크만 펼침. 물성표 삭제 → 굴곡 탄성율·성형 수축율 두 개 비교 막대 + 전체 물성표 링크. 옛 홈페이지 캡처 도해 삭제 → 2015 브로슈어 Part Application의 9개 부위만 벡터 도식과 목록으로.인덱스 세부 펼침, 목록↔도식 번호 연동, 비교 막대단독
